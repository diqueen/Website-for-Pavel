# 💻 Характеристики сервера для хостинга сайта

## 📊 Требования к оперативной памяти (RAM)

### Минимальные требования:
- **512 MB - 1 GB RAM** - для работы в режиме разработки
- **1 GB - 2 GB RAM** - для продакшн-режима с небольшим трафиком

### Рекомендуемые требования:
- **2 GB - 4 GB RAM** - для стабильной работы с умеренным трафиком
- **4 GB+ RAM** - для высокого трафика и одновременных пользователей

### Распределение памяти:

#### Backend (Node.js/Express):
- **Базовое потребление**: ~100-200 MB
- **При загрузке данных**: +50-100 MB (загрузка JSON файлов в память)
- **При обработке файлов**: +50-200 MB (временная память для обработки изображений/Excel)
- **Итого**: ~200-500 MB в зависимости от нагрузки

#### Frontend (Next.js):
- **В режиме разработки**: ~300-500 MB
- **В продакшн-режиме**: ~150-300 MB
- **При сборке**: +500-1000 MB (временное увеличение)

#### Системные процессы:
- **Операционная система**: ~200-500 MB
- **Node.js runtime**: ~50-100 MB
- **Прочие процессы**: ~100-200 MB

### Итого для продакшн:
- **Минимум**: 1 GB RAM
- **Рекомендуется**: 2-4 GB RAM
- **Для высокого трафика**: 4 GB+ RAM

## 💾 Требования к дисковому пространству (Storage)

### Базовое пространство:

#### Код проекта:
- **Frontend (Next.js)**: ~200-300 MB
  - Исходный код: ~50 MB
  - `node_modules`: ~150-200 MB
  - Собранные файлы (`.next`): ~50-100 MB
- **Backend (Express)**: ~100-150 MB
  - Исходный код: ~20 MB
  - `node_modules`: ~80-120 MB
- **Итого код**: ~300-450 MB

#### Данные (JSON файлы):
- **Товары** (4 файла): ~100 KB - 10 MB (зависит от количества товаров)
  - `products-all.json`
  - `products-ship-parts.json`
  - `products-fittings.json`
  - `products-heat-exchangers.json`
- **Услуги**: ~10-50 KB
- **Контакты**: ~5-20 KB
- **Категории**: ~5-10 KB
- **Настройки сайта**: ~1-5 KB
- **Итого данные**: ~150 KB - 15 MB

#### Загруженные файлы (`uploads/`):
- **Изображения товаров**: 
  - Максимальный размер одного изображения: **5 MB** (ограничение в коде)
  - Рекомендуемый размер: 200-500 KB на изображение
  - При 100 товарах с изображениями: ~20-50 MB
  - При 1000 товарах: ~200-500 MB
- **Excel файлы** (временные):
  - Максимальный размер: **10 MB** (ограничение в коде)
  - Обычно удаляются после обработки
  - Резерв: ~50-100 MB
- **Итого загрузки**: 
  - **Минимум**: ~50-100 MB
  - **Средний сайт**: ~200-500 MB
  - **Большой каталог**: ~500 MB - 2 GB

#### Логи:
- **Приложения**: ~10-50 MB
- **Системные**: ~50-100 MB
- **Итого**: ~60-150 MB

#### Резервное пространство:
- **Для обновлений**: ~500 MB
- **Для временных файлов**: ~200 MB
- **Буфер безопасности**: ~500 MB - 1 GB

### Итого дисковое пространство:

#### Минимальные требования:
- **Код**: ~450 MB
- **Данные**: ~15 MB
- **Загрузки**: ~100 MB
- **Логи**: ~150 MB
- **Резерв**: ~1 GB
- **ИТОГО МИНИМУМ**: **~2 GB**

#### Рекомендуемые требования:
- **Код**: ~500 MB
- **Данные**: ~50 MB
- **Загрузки**: ~500 MB
- **Логи**: ~200 MB
- **Резерв**: ~2 GB
- **ИТОГО РЕКОМЕНДУЕТСЯ**: **~3-5 GB**

#### Для большого каталога (1000+ товаров):
- **Код**: ~500 MB
- **Данные**: ~100 MB
- **Загрузки**: ~2 GB
- **Логи**: ~500 MB
- **Резерв**: ~3 GB
- **ИТОГО**: **~6-10 GB**

## 🖥️ Рекомендации по выбору хостинга

### Для небольшого сайта (до 100 товаров):
- **RAM**: 1-2 GB
- **Storage**: 5-10 GB
- **CPU**: 1-2 ядра
- **Пример**: Shared hosting, VPS начального уровня

### Для среднего сайта (100-500 товаров):
- **RAM**: 2-4 GB
- **Storage**: 10-20 GB
- **CPU**: 2-4 ядра
- **Пример**: VPS среднего уровня, облачный хостинг

### Для большого сайта (500+ товаров):
- **RAM**: 4-8 GB
- **Storage**: 20-50 GB
- **CPU**: 4+ ядра
- **Пример**: Выделенный сервер, облачный хостинг с автоскейлингом

## 📈 Масштабирование

### Оптимизация использования памяти:
1. **Использование PM2** для управления процессами Node.js
2. **Кэширование** данных в Redis (опционально)
3. **CDN** для статических файлов (изображения)
4. **Оптимизация изображений** перед загрузкой
5. **Очистка старых логов** и временных файлов

### Оптимизация дискового пространства:
1. **Сжатие изображений** перед загрузкой
2. **Использование внешнего хранилища** (S3, Cloud Storage) для изображений
3. **Регулярная очистка** временных файлов
4. **Архивация старых данных**
5. **Мониторинг использования** дискового пространства

## ⚙️ Технические детали

### Node.js требования:
- **Версия**: Node.js 18.0.0 или выше
- **npm**: 8.0.0 или выше

### Процессы:
- **Backend**: 1 процесс Node.js (Express сервер)
- **Frontend**: 1 процесс Node.js (Next.js сервер в продакшн-режиме)
- **Итого**: 2 процесса Node.js

### Порты:
- **Backend**: 5000 (или настраиваемый через PORT)
- **Frontend**: 3000 (в dev) или 80/443 (в продакшн)

---

## 📝 Примечания

1. **Размер изображений** - основной фактор, влияющий на дисковое пространство
2. **Количество товаров** - влияет на размер JSON файлов и количество изображений
3. **Трафик** - влияет на использование RAM (кэширование, обработка запросов)
4. **Логи** - могут расти со временем, требуется ротация
